# MinecraftGemini
A forked and modified version of the [AskGemini](https://github.com/Lucas-X-A/AskGemini_Minecraft_Mod) mod.

The modifications include:   
- Making Gemini able to speak in normal chat, even in online servers. 💬
- Basic command running (currently it has a race condition I haven't bothered to fix :P) 🕹️
- Giving Gemini access to the full chat since the player joined, even messages from other players and system messages. 📜
